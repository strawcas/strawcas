## Featured project

**UnderCover** is a course project that models how a travel insurer reviews claims. I built a FastAPI backend and a React dashboard around an agent that looks up policy rules, records the sources behind its decisions, and routes exceptions to a human reviewer.

I packaged the app for AWS Lambda and integrated AgentCore Gateway for tool access and AgentCore Memory for customer-specific claim history. In one local test run, the system processed **24 simulated claims in 32.1 seconds** and held all three payouts that required human sign-off.
